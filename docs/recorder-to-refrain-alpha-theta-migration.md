# Alpha/theta logic still owned by Recorder

Inventory for a later migration, recorded while adding `alpha_theta_narrowband_melodic` and checked against the three draft branches on 2026-10-09. This is a design note, not a request to move the code now. The protocol files are the source of signal and reward semantics; Recorder remains responsible for device I/O, audio rendering, media windows, and session storage. Draft PRs #101 (Refrain), #30 (protocols), and #200 (Recorder) are not release availability on `main`.

The [cross-repo feedback and review design](https://github.com/refrain-lang/refrain/blob/codex/alpha-theta-continuous-feedback/docs/superpowers/specs/2026-10-09-protocol-owned-feedback-and-review-design.md) gives the target contracts and migration order, including the shared YouTube setting that currently leaks an alpha/theta video into SMR setup.

## What has already moved

| State | Contract now outside Recorder | Remaining Recorder role |
| --- | --- | --- |
| On protocol-library `main` | `alpha_theta.refrain` defines the bands, theta threshold, delta/EMG inhibits, reward, live controls, warmup seed, session phases, and an autopilot policy. `alpha_theta_narrowband.refrain` already defines its 3–5/6–8/9–11/15–56 Hz bands, slow/fast guards, ratio reward target, controls, and phases. | Pass EEG to the evaluator, display its values, present controls, and record the session. Recorder's separate `nf/guidance.py` still makes alpha/theta-specific recommendations, so policy ownership is not fully migrated. |
| In Refrain PR #101 and protocols PR #30 | The evaluator gains `hold_for` and `at_or_above`; the narrow-band protocols emit `feedback_approach`, `feedback_crossover`, and `feedback_sustained` from their own theta/ratio/hold rules. The melodic protocol declares its asset bundle and fade defaults. | Recorder PR #200 renders those outputs and resolves the bundle. This only replaces semantic decisions when layered feedback is selected; the legacy gong path still calculates a three-second hold in Recorder. |
| In Recorder PR #200 | The layered renderer consumes the protocol's named feedback channels and the manifest reads the declared sound bundle and attack times. | Asset lookup, WAV validation, sample mixing, output routing, previews, live volume and capture remain host work. The current three-role manifest and fixed priority are still host assumptions. |

The Recorder `RefrainRunner` already passes phase transport and warmup seed results through from the evaluator (`nf/runner.py`); `nf/api.py` records their transitions. That is host integration, not a second phase/seed algorithm. The authored protocol's autopilot policy is separate from the active Recorder guidance engine; do not claim the latter has been removed or generalized.

## Decisions still in Recorder

| Priority | Recorder location and current decision | Desired Refrain contract |
| --- | --- | --- |
| 1 | `nf/audio_renderer.py` lists alpha/theta protocol IDs to choose a gong and background sample. | Protocol metadata declares feedback roles and preferred assets. Recorder resolves approved assets by role, without recognizing clinical protocol IDs. The local files themselves remain host assets. |
| 1 | The legacy `nf/audio_renderer.py:observe_telemetry` calculates a sustained theta cue from `theta_alpha_ratio` using fixed 3 s dwell, 3 s rearm, and 20 s audible interval, separate from the evaluator. | The protocol emits the semantic sustained state/event and declares any rearm requirement. Recorder enforces an audio-rate limit as playback safety, and records suppressed cues distinctly from absent evaluator events. The PR #101/#30 hold output is a partial migration, not removal of this legacy path. |
| 1 | `nf/guidance.py` assumes a `crossover_target`, theta gate, 10%/35% reward cutoffs, and gong-rate limits; `nf/api.py` instantiates and updates it by that control name. | Finish routing advice/autopilot through a protocol-declared Refrain policy and generic host adapter. The classic protocol already declares an autopilot policy; verify engine consumption and replace the separate Recorder advice path before claiming a full migration. |
| 1 | `nf/summary.py` infers theta/alpha ratios, literal crossover, shaping-target attainment, and feedback-state durations by fixed envelope/control names. | Protocol-declared measures and event labels define what is summarized. Recorder performs generic time-window aggregation and preserves raw streams. Keep literal theta-over-alpha distinct from shaping-target time. |
| 2 | `nf/texture_manifest.py` assumes exactly three roles called approach, crossover, sustained and requires aligned WAVs. | Refrain describes an ordered set of semantic feedback layers, priorities, and asset roles. Recorder validates and mixes arbitrary declared layers. |
| 2 | `nf/audio_renderer.py` fixes layer attack/release, guard-bed level, gong cooldown, and state priority. | Refrain declares per-layer transition and suppression policy, bounds, and defaults where they affect *feedback meaning*. Recorder owns the sample-accurate ramp, output ceiling, and limiter. The melodic protocol already declares two attack defaults, but the complete transition policy is not yet declarative. |
| 2 | `nf/api.py` and setup UI switch on `feedback_style == layered_texture`; `NFSetupDialog.tsx` checks `protocol_id === 'alpha_theta_narrowband'` to offer a sustained-gong preview. | Host capabilities expose available rendering styles and testable outputs from the protocol contract; UI renders controls generically. |
| 2 | `RuntimeCockpitV2.tsx` names `crossover_target` and theta gate; the observation UI inserts alpha/theta charts using fixed field names. | Protocol metadata identifies comparable streams, unit/scaling rules, literal versus shaping targets, and review metrics. Recorder draws the declared views and retains operator chart scaling. |
| 3 | YouTube defaults and media-volume behavior live in Recorder settings. | Refrain may declare that a steady external background is compatible and whether feedback may modulate it. Recorder still owns user URL, authentication/window, system volume, and output-device routing. |

The migration needs a versioned Refrain feedback schema for roles, transitions, guard behavior, and report measures, plus a generic host capability negotiation path. Do not move raw audio files, codec handling, macOS routing, YouTube login, device streaming, or capture-file I/O into the protocol language. Preserve existing captures by recording the protocol version, resolved feedback contract, asset hashes, and every live control change.

For the next pass, move one semantic behavior at a time and replay saved clean/guarded/paused telemetry through both paths before deleting host special cases. Treat authored synthetic cases as code checks, not clinical evidence; compare independently labeled real recordings separately.
