# Alpha/theta logic still owned by Recorder

Inventory for the ongoing migration, checked against the three draft branches on 2026-10-09. The protocol files are the source of signal and reward semantics; Recorder remains responsible for device I/O, audio rendering, media windows, and session storage. Draft PRs #101 (Refrain), #30 (protocols), and #200 (Recorder) are not release availability on `main`.

The [cross-repo feedback and review design](https://github.com/refrain-lang/refrain/blob/codex/alpha-theta-continuous-feedback/docs/superpowers/specs/2026-10-09-protocol-owned-feedback-and-review-design.md) gives the target contracts and migration order, including the shared YouTube setting that currently leaks an alpha/theta video into SMR setup.

## What has already moved

| State | Contract now outside Recorder | Remaining Recorder role |
| --- | --- | --- |
| On protocol-library `main` | `alpha_theta.refrain` defines the bands, theta threshold, delta/EMG inhibits, reward, live controls, warmup seed, session phases, and an autopilot policy. `alpha_theta_narrowband.refrain` already defines its 3–5/6–8/9–11/15–56 Hz bands, slow/fast guards, ratio reward target, controls, and phases. | Pass EEG to the evaluator, display its values, present controls, and record the session. Recorder's separate `nf/guidance.py` still makes alpha/theta-specific recommendations, so policy ownership is not fully migrated. |
| In Refrain PR #101 and protocols PR #30 | The evaluator gains `hold_for`, `at_or_above`, and `dwell_rearm`, plus a typed, versioned feedback declaration. The narrow-band protocols emit `feedback_approach`, `feedback_crossover`, and `feedback_sustained` from their own theta/ratio/hold rules. The older narrow-band protocol also emits a guarded, rearmed deep-gong event; the melodic protocol declares its three layers, asset roles, priorities, fade times, and a conservative automatic shaping-target policy. Active alpha/theta protocols declare the ratio stream, graded-target control, and literal threshold used in saved review. | Recorder PR #200 renders the declared channels and resolves the bundle. Its legacy renderer routes the authored deep-gong event and selects bundled gong assets from protocol metadata. No gong has been added to the melodic protocol. |
| In Recorder PR #200 | Media preferences are isolated by protocol, with external video disabled by default. The layered renderer consumes typed channel/asset declarations, accepts protocol-ordered layers and per-layer attack/release times, previews typed layers, and can play a declared event cue with a minimum audible interval. It rejects unsupported feedback suppression/gap flags. The live assistant shows Refrain's named limiter, clean-window evidence, and suggested control change; apply, dismiss, and equipment-change markers round-trip through the evaluator. An operator can enable protocol-approved automatic changes for one session, starting off each time; Recorder refuses stale EEG and records each change. Exact-history summaries use validated protocol-authored review names, while feedback-state time and layer exposure follow observed state names. | Asset lookup, WAV validation, mixing, output routing, volume ceiling and capture remain host work. Recorder retains its older guidance path for engines without the advice API. Fixed-role UI controls and other live/saved chart selection heuristics still need migration. |

The Recorder `RefrainRunner` passes phase transport, warmup seed results, and structured advice through from the evaluator (`nf/runner.py`); `nf/api.py` records their transitions. That is host integration, not a second phase/seed/advice algorithm for sessions on the pinned engine. The old Recorder guidance engine remains only as a fallback for evaluators without the advice API. Automatic application is off by default and only applies Refrain advice explicitly marked `auto_allowed` after the operator enables it; the melodic protocol is the only narrow-band variant that declares such a knob in this draft.

## Decisions still in Recorder

| Priority | Recorder location and current decision | Desired Refrain contract |
| --- | --- | --- |
| 1 | Active and retired alpha/theta protocols now declare legacy gong and background asset names. Recorder resolves them through a bundled-asset allowlist; its setup preview reads the selected protocol's metadata, and the sustained preview follows the declared cue channel. | Replace the interim legacy asset-name metadata with typed Refrain feedback roles. The local files, output routing, and safe playback ceiling remain host assets and responsibilities. |
| 1 | The older narrow-band protocol now emits `sustained_theta_cue` using `dwell_rearm`; Recorder validates the declared event channel, routes it to the deep gong, and enforces the 20 s audible interval. | Move the remaining legacy gong asset selection and preview capability out of protocol-ID branches. Recorder retains the playback rate limit and records emitted, played, and suppressed cues separately. |
| 1 | `nf/guidance.py` still assumes a `crossover_target`, theta gate, 10%/35% reward cutoffs, and gong-rate limits, but is now only the older-engine fallback. Current Refrain advice is displayed and applied generically; operator-enabled auto-application obeys the evaluator's `auto_allowed` decision and its cooldown. | Remove the old fallback after minimum-version and replay checks. Add a saved-session audit view of policy changes and compare the automatic path against representative recorded sessions before release. |
| 1 | New full captures use a validated `review_version = 1` metadata mapping for their ratio stream, shaping-target control, and literal threshold; `nf/summary.py` still retains a name-guessing decoder for older captures and fixed feedback-state names. | Refrain should gain typed named measures and presentation metadata, replacing the interim review metadata. Recorder performs generic contiguous-time aggregation and preserves raw streams. Keep literal theta-over-alpha distinct from shaping-target time. |
| 2 | `nf/texture_manifest.py` now accepts an ordered typed layer/event list, but the setup and live-control UI still names three alpha/theta roles. | Make control and preview widgets follow the declared roles; retain the legacy path only for older protocols. |
| 2 | `nf/audio_renderer.py` now reads declared attack/release and layer priority, but still fixes guard-bed level and legacy gong cooldown. | Refrain declares suppression policy and semantic events; Recorder owns the sample-accurate ramp, output ceiling, and limiter. Reject unsupported declaration flags until the host honors them. |
| 2 | `nf/api.py` and setup UI switch on `feedback_style == layered_texture`; the legacy sustained-gong preview now follows declared cue metadata. | Host capabilities expose available rendering styles and all testable outputs from the typed protocol contract; UI renders controls generically. |
| 2 | New sessions use protocol-declared numerator/denominator streams and labels for the live overview comparison; it is absent when no comparison is declared. The live assistant input list reads control labels and dwell duration from the manifest. Other live/saved review surfaces still retain fixed field names. | Replace interim comparison metadata with typed presentation and named measures; render all declared views generically and retain operator chart scaling. |
| 3 | YouTube defaults and media-volume behavior live in Recorder settings. | Refrain may declare that a steady external background is compatible and whether feedback may modulate it. Recorder still owns user URL, authentication/window, system volume, and output-device routing. |

The migration needs a versioned Refrain feedback schema for roles, transitions, guard behavior, and report measures, plus a generic host capability negotiation path. Do not move raw audio files, codec handling, macOS routing, YouTube login, device streaming, or capture-file I/O into the protocol language. Preserve existing captures by recording the protocol version, resolved feedback contract, asset hashes, and every live control change.

For the next pass, move one semantic behavior at a time and replay saved clean/guarded/paused telemetry through both paths before deleting host special cases. Treat authored synthetic cases as code checks, not clinical evidence; compare independently labeled real recordings separately.
